# DeytanLab — Site institucional

Landing page estática da DeytanLab, publicada em [deytanlab.com](https://deytanlab.com) via GitHub Pages.

## Estrutura

```
├── index.html              # Landing institucional
├── privacidade/index.html  # Política de Privacidade (LGPD)
├── termos/index.html       # Termos de Uso
└── CNAME                   # Domínio customizado (deytanlab.com)
```

## Páginas

| URL | Conteúdo |
|-----|----------|
| `/` | Landing institucional |
| `/privacidade/` | Política de Privacidade |
| `/termos/` | Termos de Uso |

## Stack

- HTML estático
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- [Font Awesome](https://fontawesome.com/) (CDN)
- Sem cookies ou analytics no site corporativo

## Deploy

O site é servido pelo GitHub Pages do repositório `DeytanLab/deytanlab.github.io`. O arquivo `CNAME` configura o domínio customizado `deytanlab.com`.
